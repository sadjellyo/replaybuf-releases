# ReplayBuf — выпуски

ReplayBuf — лёгкая программа «мгновенного повтора» для Windows 11: держит последние минуты экрана
в памяти и сохраняет их в клип по горячей клавише (по умолчанию Insert).

Здесь только готовые сборки и описания изменений — раздел **[Releases](../../releases)**:

- **`ReplayBuf-X.Y.Z-setup.exe` — установщик, для первой установки**: выбор папки, ярлыки,
  автозапуск с Windows, удаление через «Параметры → Приложения». Если Windows покажет «Система Windows
  защитила ваш компьютер» — «Подробнее» → «Выполнить в любом случае» (у программы пока нет платной
  подписи Microsoft).
- `ReplayBuf-X.Y.Z-win64.zip` — то же без установки (программа + ffmpeg): распакуйте в любую папку,
  доступную для записи, и запустите `replaybuf.exe`.
- `ReplayBuf-X.Y.Z-update.zip` — только программа; ставится сама из меню «Обновить и перезапустить».
- `latest.json` и `latest.json.sig` — описание последней версии с цифровой подписью: программа ставит
  обновление, только если подпись и контрольная сумма архива совпадают.

С версии 0.3.0 ReplayBuf сам проверяет здесь новые версии (только скачивание файлов, без
идентификаторов и статистики). Отключить: «Настройки → Дополнительно → Обновления».
